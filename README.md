# 晨霧森林

原創 2D 橫向捲軸動作 RPG（第二階段原型）。純 HTML + Canvas，單一檔案、無外部資源（圖像全部以程式繪製、音效用 WebAudio 合成），瀏覽器打開就能玩。

## 遊玩方式

- 直接用瀏覽器開啟 `index.html`
- 或在此資料夾啟動本機伺服器（手機同 Wi-Fi 可連線測試）：

```bash
python -m http.server 8000
```

然後開啟 http://localhost:8000

## 操作

| 按鍵 | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ ↓ | 攀爬繩索（附近沒有繩索時，按 ↓ 趴下；趴下時攻擊為低位攻擊） |
| 空白鍵 / Alt | 跳躍（按住 ↓ + 跳躍：從平台跳下） |
| Z / Ctrl | 普通攻擊（新手、劍士：揮砍；弓箭手：射箭；法師：短距離魔法彈） |
| X / A / S / D | 技能快捷鍵（在技能視窗中綁定） |
| 1 / 2 | 紅色藥水 / 藍色藥水 |
| ↑ / Enter | 靠近 NPC 時對話（也可直接點擊畫面中的 NPC） |
| K / I / E / Q | 技能 / 背包 / 裝備 / 任務視窗（再按一次或 Esc 關閉） |

對話框：Enter／空白鍵 繼續，←→ 選擇選項（或按數字鍵），Esc 離開。
視窗內：方向鍵選擇、Enter 執行（加點／穿上／卸下／購買／賣出），背包中 Delete 丟棄；技能視窗選中技能後按 X／A／S／D 直接綁定。
**開啟視窗或對話時遊戲會暫停**，角色不會誤動作。

觸控裝置會自動顯示虛擬按鈕：方向鍵、攻擊、跳躍、紅／藍藥水，以及 4 個技能鍵（按鈕上顯示已綁定的技能名稱）；HUD 上的「技能／背包／裝備／任務」按鈕開啟各視窗，靠近 NPC 按 ▲ 或點擊 NPC 對話。

## 系統說明

### 職業與轉職

- Lv.1 為**新手**；到 **Lv.10** 後找村口的「轉職導師 雷歐」接受轉職試煉（收集 5 個石甲碎片），完成後三選一：

| 職業 | 普攻 | 特色 | 每級成長（HP / MP / 攻擊 / 防禦） |
| --- | --- | --- | --- |
| 新手 | 近戰揮砍 | — | 14 / 7 / 3 / 0.6 |
| 劍士 | 大範圍近戰揮砍 | 轉職加成 HP+40、防禦+2；外觀為藍色鎧甲與加大的劍 | 22 / 4 / 3.6 / 1.3 |
| 弓箭手 | 射箭（射程約 500） | 轉職加成攻擊+4、爆擊率+5%；揹箭筒、羽毛頭帶、拿弓 | 15 / 7 / 3.9 / 0.7 |
| 法師 | 短距離魔法彈（射程約 260） | 轉職加成 MP+60；巫師帽、紫色長袍、法杖 | 11 / 15 / 3.5 / 0.5 |

- Lv.10 之前套用新手成長，之後套用職業成長。轉職時會獲得並自動裝備職業武器，不符合新職業的裝備會自動卸回背包。

### 技能樹

- 每升一級獲得 **3 點技能點**（新手、職業技能共用；多的點數會保留到轉職後）。
- 技能分為主動、被動、增益（buff，持續 60 秒），有等級上限與前置需求；在技能視窗（K）中以縮排呈現樹狀關係。
- 學會主動／增益技能時，會自動放到第一個空的快捷鍵；也可在視窗中點 X／A／S／D 重新綁定。

| 職業 | 技能（前置） |
| --- | --- |
| 新手 | 風刃斬（主動，Lv.10）、健體（被動 HP+，Lv.5）、└ 疾風步（被動移速+，需健體 Lv.3） |
| 劍士 | 劍術精通（被動）、└ 怒吼（增益：攻擊%，需精通 Lv.3）、重斬（主動：前方 4 體劈砍）、└ 旋風斬（主動：前後 6 體 × 3 段，需重斬 Lv.5） |
| 弓箭手 | 弓術精通（被動）、└ 集中（增益：爆擊率+移速，需精通 Lv.3）、二連射（主動）、└ 穿透箭（主動：貫穿 6 體，需二連射 Lv.5） |
| 法師 | 魔力精通（被動）、└ 魔法盾（增益：減傷%，需精通 Lv.3）、火焰球（主動：命中後範圍爆炸）、└ 雷擊（主動：前方 4 體落雷，需火焰球 Lv.5） |

### 裝備

- 欄位：**武器、帽子、衣服、鞋子、飾品**；數值：攻擊、防禦、HP、MP、爆擊率、移動速度（全部計入角色能力）。
- 稀有度：**普通**（白）、**稀有**（藍，數值 ×1.2、附加 1 條隨機屬性）、**罕見**（紫，數值 ×1.4、附加 2 條隨機屬性）；怪物掉落的裝備數值有 ±15% 浮動。
- 裝備有等級與職業限制（武器：劍 → 新手／劍士，弓 → 弓箭手，法杖 → 法師）；不符合的裝備在背包中以紅色底顯示。
- 背包（I）24 格：點選裝備可看數值、與目前裝備比較（▲▼）、穿上或丟棄（需再按一次確認）。裝備視窗（E）可卸下並查看角色總能力。
- 「商人 葛蘭」的商店：購買藥水（可一次買 10 瓶）與基本裝備，賣出背包中的裝備（稀有以上需確認）。

### 任務

城鎮 NPC 頭上會顯示「!」（可接任務）、「?」（黃色：可回報；灰色：進行中）。任務視窗（Q）顯示進度，畫面左上角會顯示追蹤中的任務（可在任務視窗切換是否追蹤）。

| # | 任務 | NPC | 條件 | 內容 | 獎勵 |
| --- | --- | --- | --- | --- | --- |
| 1 | 森林的騷動 | 村長 艾拉 | Lv.1 | 擊敗綠苔蝸 ×8 | 經驗、金幣、紅色藥水 ×5 |
| 2 | 跳跳菇的孢子 | 村長 艾拉 | Lv.4、完成 1 | 收集菇菇孢子 ×6 | 經驗、金幣、晨露項鍊（稀有） |
| 3 | 成長的證明 | 村長 艾拉 | 完成 2 | 到達 Lv.10 | 金幣、藍色藥水 ×5 |
| 4 | 轉職試煉 | 轉職導師 雷歐 | Lv.10 | 收集石甲碎片 ×5 | 經驗、**轉職**、職業武器 |
| 5 | 石甲怪的威脅 | 村長 艾拉 | 完成 4 | 擊敗石甲怪 ×10 | 經驗、金幣、職業專屬帽子（稀有） |
| 6 | 霧林深處 | 轉職導師 雷歐 | Lv.12、完成 5 | 收集霧狼之牙 ×8 | 經驗、金幣、石之心（罕見） |

任務道具只會在接取對應任務、且數量未滿時掉落。

### 地圖與怪物

- 地圖向右延伸出「**霧林深處**」（x 3600 以後，建議 Lv.12 以上），新增 4 個平台、4 條繩索與淡紫色霧氣。
- 怪物：綠苔蝸（Lv.1）、跳跳菇（Lv.4）、石甲怪（Lv.8）、**霧狼**（Lv.12，追擊速度快）、**古樹精**（Lv.15，高血量）。

### 存檔

- localStorage 自動存檔，鍵值為 `mistwood_proto_v2`，內容包含等級、經驗、金幣、藥水、職業、技能與技能點、快捷鍵、裝備、背包、任務道具與任務進度。
- 若只有第一階段的 `mistwood_proto_v1` 存檔，會自動遷移等級、經驗、金幣與藥水，並依等級補發技能點（每級 3 點）；舊存檔不會被刪除。
- 開始畫面的「重置進度」會同時清除 v1 與 v2 存檔。

## 擴充
