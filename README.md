# 晨霧森林

原創 2D 橫向捲軸動作 RPG（第四階段原型）。前端是純 HTML + Canvas 單一檔案、無外部資源（圖像全部以程式繪製、音效用 WebAudio 合成），瀏覽器打開就能玩；第三階段新增 Python Flask 後端，提供**雲端存檔**與**排行榜**；第四階段新增**霧谷遺跡與 Boss「霧之守衛」、二轉職業、設定視窗、合成音效與手機觸控操作**。

- 線上遊玩：https://peoplepop.github.io/mistwood/

## 架構

```
瀏覽器（玩家）
  │  開啟遊戲畫面
  ├──────────────► GitHub Pages：index.html（main 分支根目錄，push 後自動更新）
  │                https://peoplepop.github.io/mistwood/
  │  註冊／登入、上傳／下載存檔、排行榜（JSON API，CORS）
  └──────────────► PythonAnywhere：server/app.py（Flask + SQLite）
                   https://peoplepop.pythonanywhere.com/api/...
```

| 位置 | 內容 |
| --- | --- |
| `index.html` | 遊戲本體（前端）。開頭的 `PA_USERNAME`／`PA_DOMAIN` 決定後端網址 |
| `server/app.py` | Flask 後端（帳號、token、存檔、排行榜、CORS、錯誤處理） |
| `server/schema.sql` | SQLite 資料表（第一次連線時自動建立） |
| `server/tests/` | pytest 測試 |
| `server/requirements.txt` | 後端套件（Flask、pytest） |
| `server/DEPLOY.md` | **PythonAnywhere 部署教學**（逐步說明） |

- 在 `localhost`／`127.0.0.1` 開啟遊戲時，前端會自動改連本機後端 `http://127.0.0.1:5000`。
- 後端連不上、逾時（8 秒）或被瀏覽器擋下（例如 claude.ai Artifact 環境）時，遊戲照常可玩、本機存檔照常運作，只會顯示簡短提示。
- 若 `PA_USERNAME` 維持佔位值 `'YOUR_PA_USERNAME'`，雲端功能會顯示「雲端功能尚未設定」並停用，不會發出任何連線。

## 遊玩方式

- 直接用瀏覽器開啟 `index.html`（只有本機存檔）
- 或在此資料夾啟動本機伺服器（手機同 Wi-Fi 可連線測試）：

```bash
python -m http.server 8000
```

然後開啟 http://localhost:8000

## 本地開發（前端＋後端一起跑）

需要 Python 3.10 以上。開兩個終端機視窗：

**終端機 1：後端（Flask，127.0.0.1:5000）**

```bash
cd server
python -m venv .venv
# Windows：
.venv\Scripts\activate
# macOS / Linux：
# source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

開啟 http://127.0.0.1:5000/api/health 看到 `{"ok": true, ...}` 代表後端正常。
資料庫預設建立在 `server/mistwood.db`（已被 `.gitignore` 排除），可用環境變數 `MISTWOOD_DB` 指定其他位置。

**終端機 2：前端（專案根目錄）**

```bash
python -m http.server 8765
```

開啟 http://localhost:8765/ ，按 **L** 註冊帳號即可測試雲端存檔與排行榜。

**執行測試**

```bash
cd server
python -m pytest -q
```

### 後端 API

所有 API 都使用 JSON，錯誤一律回傳 `{"error": "繁中訊息"}`；需要登入的 API 要帶標頭 `Authorization: Bearer <token>`。

| 方法 | 路徑 | 說明 |
| --- | --- | --- |
| GET | `/api/health` | 健康檢查 |
| POST | `/api/register` | 註冊 `{username, password}` → `{token, username}`（帳號 2～12 字：英數字、底線或中文；密碼至少 6 碼） |
| POST | `/api/login` | 登入（10 分鐘內失敗 5 次會暫時鎖定） |
| POST | `/api/logout` | 登出（token 失效） |
| GET | `/api/save` | 讀取雲端存檔 `{username, save, updated_at}` |
| PUT | `/api/save` | 上傳存檔 `{save: {...}}`（上限 200KB） |
| GET | `/api/leaderboard?by=level\|kills\|gold\|boss&limit=20` | 排行榜前 N 名（`boss` = Boss 擊殺數，第四階段新增）；帶 token 時另外回傳自己的名次 `me` |

- 排行榜數值由伺服器從雲端存檔解析（`player.lv`、`player.stats.kills`、`player.coins`、`player.stats.bossKills`），不採用前端另外送的分數；並做合理性檢查（等級 1～200、金幣與擊殺數上限），不合理的存檔會被拒絕。
- CORS 只允許 `https://peoplepop.github.io` 與 `http://localhost:*`／`http://127.0.0.1:*`（可用環境變數 `MISTWOOD_EXTRA_ORIGINS` 增加）。
- 設定用環境變數：`MISTWOOD_SECRET`（token 雜湊密鑰，正式環境必填）、`MISTWOOD_DB`（資料庫路徑）。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ ↓ | 攀爬繩索（附近沒有繩索時，按 ↓ 趴下；趴下時攻擊為低位攻擊） |
| 空白鍵 / Alt | 跳躍（按住 ↓ + 跳躍：從平台跳下） |
| Z / Ctrl | 普通攻擊（新手、劍士：揮砍；弓箭手：射箭；法師：短距離魔法彈） |
| X / A / S / D | 技能快捷鍵（在技能視窗中綁定） |
| 1 / 2 | 紅色藥水 / 藍色藥水 |
| ↑ / Enter | 靠近 NPC 時對話（也可直接點擊畫面中的 NPC） |
| K / I / E / Q | 技能 / 背包 / 裝備 / 任務視窗（再按一次或 Esc 關閉） |
| L / R | 帳號（雲端存檔）/ 排行榜視窗 |
| O / Esc | 設定視窗（沒有開視窗時按 Esc 也會開啟設定） |

對話框：Enter／空白鍵 繼續，←→ 選擇選項（或按數字鍵），Esc 離開；對話中走離 NPC 會自動結束對話。
視窗內：方向鍵選擇、Enter 執行（加點／穿上／卸下／購買／賣出），背包中 Delete 丟棄；技能視窗選中技能後按 X／A／S／D 直接綁定，←→ 切換「一轉／二轉」分頁。設定視窗：←→ 調整音量、Enter 切換暫停選項、M 靜音。

**開視窗不再暫停遊戲**（和楓之谷一樣，開著背包時怪物仍會攻擊）：方向鍵、Enter、空白鍵留給視窗操作，視窗沒用到的遊戲按鍵（Ctrl／Z 攻擊、Alt 跳躍、技能鍵、1／2 藥水）照常作用；開著視窗時背包、任務進度、能力值等內容會自動更新。想要舊的行為，可在設定（O）勾選「開視窗時暫停遊戲」。

帳號視窗的輸入框打字時，按鍵不會觸發任何遊戲操作（Esc 關閉視窗、Enter 送出登入）。

### 設定（O）

- **開視窗時暫停遊戲**（預設關閉）、**主音量**滑桿、**靜音**（與畫面左上「音效」按鈕同步）、按鍵說明。
- 設定存在 localStorage 的 `mistwood_settings`（和存檔分開；讀寫都有 try/catch，無法使用 localStorage 時用預設值）。舊版的靜音設定會自動沿用。

### 音效

全部以 WebAudio 即時合成（沒有音檔），AudioContext 在第一次按鍵／點擊時才建立或恢復：揮砍、命中、爆擊、怪物倒下、升級、拾取道具、金幣、各技能施放（衝鋒、天劍、箭雨、爆裂、冰雪、隕石…）、Boss 預兆警示／吼叫／震地／倒下、介面點擊。主音量經過一個總音量節點控制。

### 手機／平板（觸控）

- 偵測到觸控裝置（`ontouchstart` 或 `pointer: coarse`）時自動顯示虛擬按鈕；桌機畫面與操作維持不變。
- **橫向（建議）**：左側方向鍵（▲▼◀▶），右側 4 個技能鍵（顯示已綁定的技能名稱）、紅／藍藥水、攻擊、跳躍。**直向**：按鈕移到畫面下方，並在上方顯示「轉為橫向」提示（可按「知道了」關閉）。
- 所有按鈕使用 Pointer Events，支援多指同時操作（例如按住方向鍵的同時攻擊）。
- 畫面左上角的「**選單**」按鈕開啟技能、背包、裝備、任務、帳號、排行榜、設定與說明（有新內容時顯示紅點）。
- 畫布會依螢幕大小自動縮放；遊戲區域禁止頁面捲動、雙擊縮放與雙指縮放（視窗內容仍可捲動）。靠近 NPC 按 ▲ 或點擊 NPC 對話。

## 系統說明

### 職業與轉職

- Lv.1 為**新手**；到 **Lv.10** 後找村口的「轉職導師 雷歐」接受轉職試煉（收集 5 個石甲碎片），完成後三選一：

| 職業 | 普攻 | 特色 | 每級成長（HP / MP / 攻擊 / 防禦） |
| --- | --- | --- | --- |
| 新手 | 近戰揮砍 | — | 14 / 7 / 3 / 0.6 |
| 劍士 | 大範圍近戰揮砍 | 轉職加成 HP+40、防禦+2；外觀為藍色鎧甲與加大的劍 | 22 / 4 / 3.6 / 1.3 |
| 弓箭手 | 射箭（射程約 500） | 轉職加成攻擊+4、爆擊率+5%；揹箭筒、羽毛頭帶、拿弓 | 15 / 7 / 3.9 / 0.7 |
| 法師 | 短距離魔法彈（射程約 260） | 轉職加成 MP+60；巫師帽、紫色長袍、法杖 | 11 / 15 / 3.5 / 0.5 |

- Lv.10 之前套用新手成長，之後套用職業成長。轉職時會獲得並自動裝備職業武器，不符合新職業的裝備會自動卸回背包。

#### 二轉（第四階段）

到 **Lv.30** 並完成「沉睡的遺跡」後，找轉職導師雷歐接受「二轉試煉」（收集 10 個古代符文石），每個一轉職業各有一條二轉路線：

| 一轉 | 二轉（存檔 id） | 二轉加成 | Lv.30 之後每級成長（HP / MP / 攻擊 / 防禦） | 外觀 |
| --- | --- | --- | --- | --- |
| 劍士 | **騎士**（`knight`） | HP+160、防禦+8、攻擊+8（含一轉加成） | 27 / 5 / 4.3 / 1.7 | 白披風、金色飾邊與頭飾、更大的劍 |
| 弓箭手 | **獵人**（`hunter`） | 攻擊+14、爆擊率+10%、HP+60 | 18 / 8 / 4.7 / 0.9 | 墨綠服裝、第二根紅羽毛 |
| 法師 | **巫師**（`wizard`） | MP+180、攻擊+8、HP+40 | 13 / 18 / 4.4 / 0.6 | 深藍長袍、紫披風、帽上金星 |

- 二轉職業在所有判斷上都視為所屬的一轉職業（`jobLine()`／`JOBS[id].base`）：一轉的裝備、武器類型與一轉技能都能繼續使用。二轉時不更換武器。
- 成長：Lv.1～10 新手、Lv.10～30 一轉、Lv.30 之後二轉（還沒二轉就繼續套用一轉成長）。

### 技能樹

- 每升一級獲得 **3 點技能點**（新手、職業技能共用；多的點數會保留到轉職後）。
- 技能分為主動、被動、增益（buff，持續 60 秒），有等級上限與前置需求；在技能視窗（K）中以縮排呈現樹狀關係。
- 學會主動／增益技能時，會自動放到第一個空的快捷鍵；也可在視窗中點 X／A／S／D 重新綁定。

| 職業 | 技能（前置） |
| --- | --- |
| 新手 | 風刃斬（主動，Lv.10）、健體（被動 HP+，Lv.5）、└ 疾風步（被動移速+，需健體 Lv.3） |
| 劍士 | 劍術精通（被動）、└ 怒吼（增益：攻擊%，需精通 Lv.3）、重斬（主動：前方 4 體劈砍）、└ 旋風斬（主動：前後 6 體 × 3 段，需重斬 Lv.5） |
| 弓箭手 | 弓術精通（被動）、└ 集中（增益：爆擊率+移速，需精通 Lv.3）、二連射（主動）、└ 穿透箭（主動：貫穿 6 體，需二連射 Lv.5） |
| 法師 | 魔力精通（被動）、└ 魔法盾（增益：減傷%，需精通 Lv.3）、火焰球（主動：命中後範圍爆炸）、└ 雷擊（主動：前方 4 體落雷，需火焰球 Lv.5） |
| 騎士 | 鋼鐵意志（被動：防禦、HP）、└ 守護光環（增益：減傷%＋攻擊%，需意志 Lv.3）、衝鋒突刺（主動：向前衝刺貫穿 8 體，衝刺中無敵）、└ 天劍降臨（主動：巨大光之劍落下，範圍 8 體，需衝鋒 Lv.5） |
| 獵人 | 獵人本能（被動：攻擊、爆擊率）、└ 鷹眼（增益：攻擊%＋爆擊率，需本能 Lv.3）、箭雨（主動：前方 3 波箭雨，每波 8 體）、└ 爆裂箭（主動：命中後爆炸 6 體，需箭雨 Lv.5） |
| 巫師 | 元素精通（被動：攻擊、MP）、└ 魔力湧泉（增益：攻擊%＋持續回復 MP，需精通 Lv.3）、暴風雪（主動：4 次冰雹、每次 8 體並緩速）、└ 隕石術（主動：砸向前方最近的敵人，範圍 10 體，需暴風雪 Lv.5） |

- 技能視窗分為「**一轉**」（新手＋一轉技能）與「**二轉**」兩個分頁；尚未二轉時，二轉分頁會預覽對應職業的技能。二轉技能一樣可綁定到 X／A／S／D，並各有專屬特效（殘影、光劍、箭雨、爆炸、冰晶、隕石）。

### 裝備

- 欄位：**武器、帽子、衣服、鞋子、飾品**；數值：攻擊、防禦、HP、MP、爆擊率、移動速度（全部計入角色能力）。
- 稀有度：**普通**（白）、**稀有**（藍，數值 ×1.2、附加 1 條隨機屬性）、**罕見**（紫，數值 ×1.4、附加 2 條隨機屬性）、**傳說**（金，數值 ×1.7、附加 3 條隨機屬性，只會從 Boss 身上掉落，地上有更亮的金色光柱）；怪物掉落的裝備數值有 ±15% 浮動。
- 裝備有等級與職業限制（武器：劍 → 新手／劍士／騎士，弓 → 弓箭手／獵人，法杖 → 法師／巫師）；不符合的裝備在背包中以紅色底顯示。
- 第四階段新增 Lv.20～28 裝備：商店販售 **破甲大劍／遺跡反曲弓／符文法杖**（Lv.20 武器）與 **遺跡戰靴**；只能靠掉落取得的有 **守衛者之刃／風翼長弓／霧月法杖**（Lv.28 武器）、**騎士頭盔／獵人羽帽／巫師尖帽**（Lv.22）、**遺跡板甲／獵人皮衣／星紋長袍**（Lv.25）、**霧之護符**（Lv.26 飾品）。
- 背包（I）24 格：點選裝備可看數值、與目前裝備比較（▲▼）、穿上或丟棄（需再按一次確認）。裝備視窗（E）可卸下並查看角色總能力。
- 「商人 葛蘭」的商店：購買藥水（可一次買 10 瓶）與基本裝備，賣出背包中的裝備（稀有以上需確認）。

### 地圖與怪物

- 地圖向右延伸出「**霧林深處**」（x 3600 以後，建議 Lv.12 以上），新增 4 個平台、4 條繩索與淡紫色霧氣。
- 第四階段再延伸出「**霧谷遺跡**」（x 4850～7400，建議 Lv.18 以上）：石板路面、石造平台、背景斷柱，天色轉為灰紫；入口有新 NPC「遺跡學者 希爾妲」。最右邊是 Boss 區「**守衛祭壇**」（x 6700 以後，石拱門、符文石牆，祭壇內有 2 個躲避用平台）。進入新區域時畫面中央會顯示區域名稱，小地圖標題顯示目前區域、Boss 以紅框方塊標示。
- 怪物：綠苔蝸（Lv.1）、跳跳菇（Lv.4）、石甲怪（Lv.8）、**霧狼**（Lv.12，追擊速度快）、**古樹精**（Lv.15，高血量）、**遺跡石偶**（Lv.18，掉落古代符文石）、**霧魂**（Lv.22，飄浮、追擊快，掉落霧魂結晶）、**亡靈騎士**（Lv.26，高攻擊）。遺跡怪物經驗值 190／290／420，Lv.15→30 約需 6.8 萬經驗（任務另給約 3 萬）。

### Boss：霧之守衛（Lv.30）

- 位於守衛祭壇，HP 22000。畫面上方會出現 Boss 血條（含名稱、百分比與 50% 刻度）。
- 三種招式，出招前頭上會出現紅色「!」並有預兆：**衝撞**（地面出現紅色箭頭區域，快速衝到祭壇另一端）、**震地**（舉起雙臂，地面變紅，向左右送出震波——跳起來或站上平台即可躲開）、**霧彈齊射**（胸口核心發光、虛線瞄準，射出 5 發扇形霧彈）。
- HP 剩一半時**狂暴化**：裂縫與核心轉紅、速度變快、出招間隔縮短，衝撞會連續 2 次、震地會送出 2 輪震波、霧彈增為 7 發。
- 玩家離開祭壇（或倒下）6 秒後 Boss 會回滿血；擊敗後 **3 分鐘**重生。
- 必定掉落：大量金幣、紅／藍藥水各 3、**1 件適合自己職業的罕見以上裝備（25% 為傳說）**、另 1 件隨機裝備（10% 傳說）。
- 擊敗次數記錄在 `player.stats.bossKills`，顯示於裝備視窗（E）與帳號視窗（L），並可在排行榜「Boss」分頁比較。

### 雲端存檔與排行榜（第三階段）

- 按 **L**（或 HUD「帳號」）開啟帳號視窗：註冊、登入、登出，並顯示登入狀態、雲端連線狀態與最後同步時間；也可按「立即同步」。
- 登入期間，本機存檔時會同步上傳雲端：一般情況最多每 30 秒一次；**升級、轉職、完成任務**時約 1.5 秒內上傳；切到背景（例如手機切換 App）與登出前也會上傳。
- 登入時若雲端與本機都有存檔且內容不同，會並列顯示兩邊的職業／等級／金幣／擊殺數／更新時間，讓玩家選擇要使用哪一份（需按兩下確認，另一份會被覆蓋）；選擇前不會自動上傳。本機沒有進度時會直接載入雲端存檔。
- 已登入狀態重新開啟遊戲時，會在背景比對：兩邊相同就不打擾；本機較新就上傳；雲端較新（例如在其他裝置玩過）則提示按 L 選擇，HUD「帳號」按鈕出現紅點。
- 按 **R** 開啟排行榜：可切換「等級／擊殺數／金幣／Boss」（←→），顯示前 20 名，自己的那一列以藍框標示，下方顯示自己的名次；職業欄會正確顯示二轉職業名稱。若後端尚未更新、不支援 `by=boss`，Boss 分頁會顯示「即將開放」的說明，不影響其他分頁。
- 開始畫面的「**重置進度**」需要再按一次「確定重置」：只會清除這台裝置的進度，**不會登出雲端帳號**；重置後的新進度會照常同步（約數秒內），**雲端存檔會被覆蓋**，畫面上會明確提示。
- 登入 token 存在 localStorage 的 `mistwood_cloud`，有效期 30 天。

### 存檔

- localStorage 自動存檔，鍵值為 `mistwood_proto_v2`，內容包含等級、經驗、金幣、藥水、職業、技能與技能點、快捷鍵、裝備、背包、任務道具與任務進度，以及第三階段新增的 `player.stats.kills`（累計擊殺數，舊存檔從 0 開始）與 `savedAt`（存檔時間，用來比對本機與雲端）。裝備視窗（E）會顯示累計擊殺數。
- 第四階段沿用同一個鍵值，新增 `player.stats.bossKills`（舊存檔從 0 開始）；`player.job` 可能是二轉職業 id（`knight`／`hunter`／`wizard`），裝備稀有度可能是 3（傳說）。缺少的新欄位一律使用預設值，舊存檔可直接讀取。
- 若只有第一階段的 `mistwood_proto_v1` 存檔，會自動遷移等級、經驗、金幣與藥水，並依等級補發技能點（每級 3 點）；舊存檔不會被刪除。
- 開始畫面的「重置進度」會同時清除 v1 與 v2 存檔。

## 擴充

數值集中在 `index.html` 腳本開頭的資料區：`JOBS`（職業成長／普攻；二轉以 `base` 指向一轉）、`JOB2_OF`、`SKILLS`（技能）、`ITEMS`／`RARITY`（裝備）、`MONSTERS`、`BOSS_LOOT`、`QUESTS`、`NPCS`、`SHOP_LIST`、`EXP_TABLE`、`PLATFORMS`／`ROPES`／`SPAWNS`（地圖）、`RUIN_X`／`ARENA_X`（區域邊界）。Boss 招式參數在 `BOSS`（衝撞速度、震波速度與距離、霧彈速度、脫離戰鬥回血秒數）。
