# 晨霧森林

原創 2D 橫向捲軸動作 RPG（第一階段原型）。純 HTML + Canvas，單一檔案、無外部資源，瀏覽器打開就能玩。

## 遊玩方式

- 直接用瀏覽器開啟 `index.html`
- 或在此資料夾啟動本機伺服器（手機同 Wi-Fi 可連線測試）：

```bash
python -m http.server 8000
```

然後開啟 http://localhost:8000

## 操作

| 按鍵 | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ ↓ | 攀爬繩索（附近沒有繩索時，按 ↓ 趴下；趴下時攻擊為低位突刺） |
| 空白鍵 / Alt | 跳躍（按住 ↓ + 跳躍：從平台跳下） |
| Z / Ctrl | 普通攻擊 |
| X | 技能「風刃斬」（消耗 8 MP） |
| 1 / 2 | 紅色藥水 / 藍色藥水 |

觸控裝置會自動顯示虛擬按鈕。

## 目前內容

- 一張地圖（地面 + 三層平台、6 條繩索、視差背景、小地圖）
- 3 種怪物：綠苔蝸、跳跳菇、石甲怪
- 經驗值與升級、金幣與藥水掉落、技能冷卻
- 死亡與重生、localStorage 自動存檔

## 擴充

怪物、經驗表、角色成長等數值集中在 `index.html` 腳本開頭的資料區（`MONSTERS`、`EXP_TABLE`、`PLAYER_GROWTH`、`SPAWNS`）。

## 線上版

另有發布於 claude.ai 的 Artifact 版本。Artifact 版不含檔案開頭的 `<!doctype>`、`<html>`、`<meta>` 四行（由平台自動補上），其餘內容與本檔相同。
